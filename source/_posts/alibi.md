> 本文是对 Press et al., 2021《Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation》的阅读笔记，原文见 arXiv:2108.12409（https://arxiv.org/abs/2108.12409）。文中只整理论文公开的核心思想，不补充原文之外的具体数字。

## TL;DR

- ALiBi 不使用传统意义上的位置嵌入，而是直接在注意力分数上按 query 与 key 的距离施加一个线性惩罚：距离越远，惩罚越大。
- 这种偏置让模型可以在较短序列上训练、却外推到比训练时更长的序列，且不出现明显的性能塌陷，即论文标题所说的 "train short, test long"。
- 方法实现简单、几乎不增加额外计算与显存成本，因此成为长度外推领域被广泛引用的经典方案之一。
- 它把"位置"信息从被显式编码的特征，转变为注意力机制内部对距离的一种结构性归纳偏置。

## 一、背景与动机

Transformer 的自注意力本身对输入顺序是不敏感的——若不引入额外信息，打乱 token 顺序不会改变注意力的计算结果。因此模型需要某种方式感知"位置"。早期常见做法包括正弦位置编码与可学习的绝对位置嵌入，它们把位置信息以向量的形式加到词嵌入上。

这类方案在训练长度范围内通常表现良好，但当推理阶段的序列长度超过训练时见过的最大长度时，模型往往难以稳定泛化：它没有学习过更大的位置索引对应的表示，外推能力受限。这正是 ALiBi 试图解决的问题：能否让一个只在短序列上训练过的模型，在更长的输入上仍然保持可用的表现，从而把"训练成本"与"可处理长度"解耦。

## 二、核心思想：在注意力分数上加线性偏置

ALiBi 的做法可以概括为一句话：去掉加在输入上的位置嵌入，转而在每一对 query–key 的注意力打分上，按它们之间的距离减去一个与距离成正比的值。

逐点拆解其要点：

- **作用位置不同。** 传统位置编码作用在输入嵌入层；ALiBi 作用在注意力分数（softmax 之前）上，是对注意力打分矩阵的直接修改。
- **偏置形如线性惩罚。** 对于一个 query 与其前面距离为若干步的 key，距离越大，被减去的惩罚越大；因此模型在计算注意力时天然更倾向于关注较近的位置。
- **每个注意力头有不同的斜率。** 不同的头使用不同强度的惩罚（斜率），使得有的头偏向局部、有的头能照顾到更远的上下文，从而在"近因偏好"和"长程信息"之间形成分工。
- **没有可学习的位置参数。** 偏置由固定的距离结构与预设斜率决定，不引入需要训练的位置向量。

这种设计的直觉在于：与其让模型去"记住"每个绝对位置长什么样，不如把"距离越远、关联应越弱"这一先验，直接以结构化偏置的形式写进注意力里。

```mermaid
flowchart LR
    A[Query 与 Key 的点积分数] --> B[按距离加线性惩罚<br/>越远惩罚越大]
    B --> C[Softmax]
    C --> D[注意力权重<br/>偏向较近位置]
```

## 三、与传统位置编码的对比

下表从几个维度对比 ALiBi 与常见的绝对位置编码思路，便于把握其定位：

| 维度 | 传统绝对位置嵌入 | ALiBi |
| --- | --- | --- |
| 信息注入位置 | 输入嵌入层 | 注意力分数（softmax 前） |
| 位置信息形式 | 显式的位置向量 | 基于距离的线性惩罚 |
| 是否引入位置参数 | 通常需要 | 不需要 |
| 对超出训练长度的输入 | 外推往往受限 | 支持外推到更长序列 |
| 额外计算/显存开销 | 取决于实现 | 几乎可忽略 |

需要强调的是，上表是对思路差异的定性归纳，不同实现的具体效果会随模型规模、数据与任务而变化。

## 四、为什么有助于长度外推

ALiBi 之所以利于外推，关键在于它表达位置关系的方式具有"可平移、可延伸"的性质：注意力对位置的依赖被表述为对相对距离的单调惩罚，而不是绑定在某个具体的绝对位置索引上。当输入变长、出现训练时未见过的距离时，这套基于距离的惩罚规则仍然可以自然地延续下去，而不需要查表得到一个从未学习过的位置表示。

由此带来的工程价值是直接的：可以用较短的训练序列控制训练开销，同时在推理时面对更长的上下文。这也是论文标题 "train short, test long" 的字面含义。

## 意义与局限

ALiBi 的意义在于，它用一种极简、低成本的方式重新组织了 Transformer 中"位置"的表达：从加在输入上的显式嵌入，转为注意力内部对距离的结构性归纳偏置，并以此获得了较好的长度外推能力。其实现简单、几乎不增加成本的特点，使它易于集成，并在后续的位置编码与长度外推讨论中被反复引用。

局限方面也应客观看待。ALiBi 通过对远距离施加惩罚来获得外推能力，这本质上是一种偏向近因的归纳偏置，对那些高度依赖远距离精确位置关系的任务是否同样适用，需要结合具体场景评估。此外，长度外推是一个活跃的研究方向，存在多种不同取向的方案，它们各有适用边界，难以一概而论。把 ALiBi 理解为长度外推问题中的一个经典且简洁的参照点，比把它视为唯一解更为稳妥。
