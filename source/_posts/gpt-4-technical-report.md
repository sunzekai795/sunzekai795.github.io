> 本文是对 OpenAI 于 2023 年发布的技术报告《GPT-4 Technical Report》(arXiv:2303.08774，链接：https://arxiv.org/abs/2303.08774) 的阅读笔记与解读。需要说明的是，该报告本身明确表示出于竞争与安全方面的考虑，未披露模型规模、数据集与训练细节，因此本文的讨论也限定在报告所给出的公开范围之内。

## TL;DR

- GPT-4 是一个大型多模态模型，可接受文本与图像输入、输出文本，并在大量专业与学术考试上达到接近人类的水平。
- 报告刻意未公开模型规模、数据构成与训练方法，理由是竞争与安全，这一选择本身在业界引发了关于开放性的讨论。
- 报告强调「可预测扩展」：用远小于最终模型的算力进行实验，从而提前预测大模型的能力与损失。
- 报告以相当篇幅讨论安全、RLHF 对齐与风险评估，同时坦承技术细节有限。

## 一、定位：从语言模型到多模态系统

GPT-4 在报告中被定位为一个大型多模态模型。与以往以纯文本为主的语言模型不同，它能够同时接受文本与图像作为输入，并以文本形式输出。这意味着模型可以处理「图文混合」的任务，例如阅读包含图表、截图或手写内容的材料并据此作答。

需要注意的是，这种多模态能力是「输入侧」的扩展：模型理解图像，但其产物仍然是文本。这一设计延续了 GPT 系列以文本为核心的交互范式，同时把可感知的模态边界向视觉拓展。

## 二、能力跃迁：考试作为度量

报告中最具传播力的部分，是 GPT-4 在大量为人类设计的专业与学术考试上的表现。报告指出，模型在这些考试上达到了接近人类的水平，其中一个被反复引用的例子是：在模拟律师资格考试中，GPT-4 的成绩名列前茅。

用「人类考试」来度量模型能力，是一种直观且具有外部参照的评估方式。它的优点是结果易于理解、与现实任务相关；但也存在局限：考试题目可能与训练数据存在重叠，且考试能力并不等同于真实世界中的可靠性。报告对这类评估给出了结果，但能力强弱与适用边界仍需结合具体场景判断。

下面用一张表概括报告中几个关键维度的取向：

| 维度 | 报告中的取向 |
| --- | --- |
| 模态 | 文本与图像输入，文本输出 |
| 能力度量 | 大量专业与学术考试，部分接近人类水平 |
| 技术细节 | 刻意未披露规模、数据与训练方法 |
| 扩展性 | 强调可预测扩展 |
| 篇幅重点 | 安全与对齐占据相当比重 |

## 三、可预测扩展：把不确定性前移

报告强调的一项工程方法论是「可预测扩展」(predictable scaling)。其核心思想是：在投入巨大算力训练最终模型之前，先用规模小得多、算力消耗低得多的实验，去预测大模型最终的损失与部分能力表现。

这一点的意义在于把大模型训练中的不确定性「前移」。训练超大模型代价高昂，一旦方向有误，成本难以承受。如果能够通过小规模实验外推出最终结果，团队就能在更早的阶段做出更可靠的决策。报告把这种可预测性作为其研发体系的一部分加以呈现。

```mermaid
flowchart LR
    A[小规模实验] --> B[拟合扩展规律]
    B --> C[预测大模型损失与能力]
    C --> D[决策与最终训练]
```

## 四、刻意留白：开放性的取舍

报告区别于以往技术报告的一个显著特征，是它的「留白」。报告明确说明，出于竞争与安全方面的考虑，不再披露模型的参数规模、数据集构成与具体训练方法，并在文中点明「技术细节有限」。

这种处理方式在业界引发了讨论。一方面，开放细节有助于复现、审计与共同改进；另一方面，发布方提出的竞争与安全顾虑也有其现实背景。无论立场如何，这份报告都标志着前沿模型在「公开程度」上的一种转向：它更像一份能力与安全的说明，而非可供复现的技术蓝图。

## 五、安全与对齐：报告的另一半重量

除了能力展示，报告以相当篇幅讨论安全问题。其中包括使用基于人类反馈的强化学习(RLHF)进行对齐，以及围绕模型潜在风险展开的评估工作。报告关注的风险面较广，涉及模型可能产生的有害或不真实输出，以及在实际部署中需要的缓解措施。

把安全与能力放在同等显著的位置，反映出前沿模型发布时的重心变化：模型「能做什么」与「应当如何被约束」被同时纳入叙述。报告对这部分给出了定性的描述与方法说明，但同样受限于其整体的「细节有限」原则。

## 意义与局限

GPT-4 技术报告的意义，在于它同时呈现了一次明显的能力跃迁与一种新的发布范式：多模态输入、接近人类水平的考试表现、以及把可预测扩展纳入研发流程。它让外界看到前沿模型在能力上的进展，也展示了团队在安全与对齐上的投入。

其局限同样清晰。由于刻意未披露规模、数据与训练细节，报告难以支撑独立复现与深入审计；以考试成绩为主的能力度量也无法完全代表真实场景中的可靠性。换言之，这是一份关于「结果与态度」的报告，而非关于「方法」的报告。理解 GPT-4，需要把它放在这种公开与保留并存的语境中来看。
